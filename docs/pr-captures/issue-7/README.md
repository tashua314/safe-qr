# Issue #7の画面確認

2026-10-15、Xcode 26.6 / iOS 26.5 / 専用iPhone 16 Pro Simulator、Debug、1206×2622 pixels。

`scanner-camera-unavailable.png` はアプリ本体の起動後にSimulatorでカメラが使用できない状態。スキャン画面と許可案内が表示されることを確認した。撮影、ライト、実際のQR読取りはこの画像で確認できない。UIテスト6件は起動・起動時間・各UI設定の起動キャプチャが中心で、設定や履歴の操作フローの検証を示すものではない。

Xcodeの環境不整合で旧状態を起動できなかったため、同一環境の変更前画像は取得できていない。セル分離や強制アンラップの除去は表示仕様を変更しない方針で行い、実際の操作フローの追加確認はIssue #8で記録する。
