# 要件と現在の実装範囲

2026-10-15更新。以下は製品の狙い・要件であり、実機検証済みを意味しない。実装と検証の状態は[release-validation.md](release-validation.md)を正本とする。

### 1. 目的と制約
- 目的: 迷わず使えるQRリーダー。危険リンクは事前警告。履歴はタイトル付き保存。
- ターゲット: ITリテラシー低め（高齢者/非IT職）
- 最低OS: **iOS/iPadOS 18.5**
- プライバシー: 履歴は端末内（最大50件）。外部チェック・対象サイト通信は各仕様の説明に従う
- 外部レピュテーション: 任意・既定OFF。Googleの利用条件と配布用途は公開前に確定する
- テレメトリ: 独自のクラッシュ/分析送信は未実装。OS診断は利用者のOS設定に従う。追加する場合は別途方針を確定する
- 申請情報: 運営者・サポート窓口・公開URL・利用条件を確定するまで下書き

### 2. 要件整理
#### 2.1 機能要件（ユーザーストーリー）
| ID | 利用者 | ニーズ（やりたいこと） | 目的・メリット |
|---|---|---|---|
| US-1 | 一般 | 開いたらすぐ読み取り | 迷わず使える |
| US-2 | 一般 | 危険度がわかる | 被害回避 |
| US-3 | 一般 | 注意・危険・外部未確認時に確認画面 | 誤タップ防止 |
| US-4 | 一般 | 履歴（タイトル付）が欲しい | 再訪が楽 |
| US-5 | 一般 | 履歴は最大50件で十分 | シンプル維持 |
| US-6 | 一般 | 共有/コピー/外部ブラウザも可（将来候補・独自UI未実装） | 活用範囲拡大 |
| US-7 | 一般 | 文字大きめ/分かりやすい色 | 読みやすい |
| US-8 | 一般 | オフラインでも最低限動作 | 安心 |
| US-9 | 一般 | 開封許可後にタイトル取得、失敗時はURL表示 | 見やすさ |

#### 2.2 非機能要件
- 操作回数最小（起動＝読み取り）
- アクセシビリティの目標はDynamic Type、明確な色、簡潔な文言。実機の大文字・VoiceOverでの全画面確認は未完了
- カメラ起動<1sは目標値。実機カメラの測定値はまだない
- プライバシー（Google安全性照会はSHA-256の先頭4バイト。タイトル取得とブラウザ表示は対象サイトへ通信）
