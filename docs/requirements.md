### 1. ヒアリング結果サマリー
- 目的: 迷わず使えるQRリーダー。危険リンクは事前警告。履歴はタイトル付き保存。
- ターゲット: ITリテラシー低め（高齢者/非IT職）
- 最低OS: **iOS 10**
- プライバシー: 個人情報収集なし、履歴は端末内（最大50件）
- 外部レピュテーション: 使用 **OK**
- テレメトリ: 匿名クラッシュ収集 **許可**
- 法務: **不要**

### 2. 要件整理
#### 2.1 機能要件（ユーザーストーリー）
| ID | 利用者 | ニーズ（やりたいこと） | 目的・メリット |
|---|---|---|---|
| US-1 | 一般 | 開いたらすぐ読み取り | 迷わず使える |
| US-2 | 一般 | 危険度がわかる | 被害回避 |
| US-3 | 一般 | 警告時のみ確認画面 | 誤タップ防止 |
| US-4 | 一般 | 履歴（タイトル付）が欲しい | 再訪が楽 |
| US-5 | 一般 | 履歴は最大50件で十分 | シンプル維持 |
| US-6 | 一般 | 共有/コピー/外部ブラウザも可 | 活用範囲拡大 |
| US-7 | 一般 | 文字大きめ/分かりやすい色 | 読みやすい |
| US-8 | 一般 | オフラインでも最低限動作 | 安心 |
| US-9 | 一般 | タイトル取れない時は後追い取得 | 見やすさ |

#### 2.2 非機能要件
- 操作回数最小（起動＝読み取り）
- アクセシビリティ（Dynamic Type、明確な色、簡潔な文言）
- パフォーマンス（カメラ起動<1s目標）
- プライバシー（外部送信はドメインハッシュ等の最小限）
