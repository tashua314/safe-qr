# 危険判定ロジック

## 端末内スコアリング例
- Punycode/紛らわしい文字混在（+3）
- IP直打ちURL（+2）
- サブドメイン深さ>3（+1）
- パス/クエリ極端に長い（+1〜2）
- 有名ブランド語を含むが公式ドメインでない（+3）
- 疑義TLD（例 .zip .mov）（+1）

合計 → `0-1: safe / 2-3: caution / 4+: danger`  
厳しさ：`high` は +1、`low` は -1（下限0）

## 外部レピュテーション照会
- 入力：**ドメインのハッシュ**（例：SHA256）や eTLD+1 のみ
- 出力：危険/注意/不明（SafetyLevel?）
- フォールバック：タイムアウト/エラー時は**端末内スコアのみ**

## プライバシー
- URL生値は**送信しない**
- ログにURLを残さない（匿名クラッシュのみ）
