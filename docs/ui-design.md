# UI/コピー/配色方針（やさしめ）

## 画面
- **スキャン**（起動直後）
  - ガイド文：*「QRコードにかざしてください」*
  - ボタン：左上「履歴」、右上「設定」
- **警告ダイアログ**
  - danger: タイトル *「危険な可能性があります」* ／本文 *「開かないことをおすすめします」*
    - ボタン：**ブロック（推奨）**／**自己責任で開く**
  - caution: タイトル *「不審な可能性があります」* ／本文 *「確認してから開いてください」*
    - ボタン：**やめる**／**続行する**
- **履歴**（Table）
  - 太字タイトル／小さくドメイン／右にバッジ（SAFE/注意/危険）
  - スワイプ削除／右上「編集」「すべて削除」
  - 空状態：「まだ履歴はありません」「QRを読み取るとここに表示されます」
- **設定**
  - 安全確認の厳しさ：弱・標準・強（説明つき）
  - 外部チェック：オン/オフ（個人情報は送信しません）
  - 履歴：最大50件（固定で説明表示）

## 配色（識別しやすさ）
- **安全**: 落ち着いた緑系
- **注意**: 橙系
- **危険**: 赤系（強調）
- ボタンは太文字＋大きめタップ領域（44pt以上）
